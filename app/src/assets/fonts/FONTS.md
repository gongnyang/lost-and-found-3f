## 나눔명조 woff2 서브셋 관련 참고

이 레포의 나눔명조 woff2 파일들은 원본 배포본에서 웹 사용을 위해
글리프를 서브셋(subset)한 수정본(Modified Version)이다. OFL 1.1 제3조의
예약글꼴명(Reserved Font Name) 조항에 따라, 수정본은 예약글꼴명을 기본
표시 이름으로 사용할 수 없다는 점에 유의할 것. 본 프로젝트에서는 내부
CSS `font-family` 참조 용도로만 사용하며, 파일을 재사용할 경우 이
조항을 스스로 확인해야 한다.
