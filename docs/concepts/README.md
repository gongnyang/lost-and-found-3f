# 웹 미연시 스토리 컨셉 시안 3종

**스코프 공통**: 공통 1~2챕터 + 히로인별 2~3챕터 + 굿/트루 엔딩, 플레이 30~60분, 총 대사 2.5~2.6만자
**공통 제약**: 한국 배경, 한국식 이름, 히로인 3인(여동생/동급생/누나 타입 — **전원 비혈연**), SD 턴제 전투 2~3회 삽입

## 추천

**B(『분실물 보관소, 3층 D열』)를 추천한다** — 전투가 서사에 완전히 종속되면서(검열자 → 환각 → UI 해체) 동시에 반전의 뇌관 역할까지 겸하고, 게임 시작 시 「???」였던 이름 입력창을 엔딩에서 여는 시스템 연출이 30~60분 스코프에서 가장 큰 감정 진폭을 만든다.

- 안정적으로 눈물 착지를 원한다면 → **A** (가장 적은 공수로 가장 확실한 여운)
- 전투 비중을 크게 가져가거나 후속작·세계관 확장을 염두에 둔다면 → **C**
- 대안: **B의 반전 구조 + A의 잔잔한 일상 밀도**를 절충하는 하이브리드도 가능하다 (보관소 설정 유지 + 히로인 러브코미디 분량을 A 수준으로 증량, 총 3만자 상한).
