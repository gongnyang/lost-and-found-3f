## 직전 상황 3줄 (스포일러 포함)
1. 하람은 리원의 수첩에서 「오늘도 잊지 마 / 네가 지웠어」 두 조각을 읽었고, 가운데는 못 봤다.
2. 3년 전 10월분 학생회 회의록은 결번이다. 사고 기록 일체를 폐기하기로 한 결의였고, 서기 서명은 열네 살의 리원이다. — **이 씬에서 "결번"과 "서명 존재"까지만 드러난다. 폐기 대상이 무엇인지는 금지.**
3. 리원이 D열에 맡긴 물건은 부러진 펜이다. 그 결의안에 서명할 때 쓴 펜. — **개봉 전까지 정체 금지.**

## 이 씬의 목표
- **플롯**: 결번 발견 → 추궁 → 리원이 맡긴 물건 개봉 → 전투2.
- **감정**: 이 루트에서 처음으로 둘이 정면 대치한다. 리원은 끝까지 방어에 성공한다.
- **구조적 기능(최중요)**: **환각 단서 `F19`(소독약·링거)와 `F20`(검열자가 아는 정보만 말함)을 심는다.** 1회차 반발 방지 장치. 누락 시 재작업.

## 비트 시퀀스 (권장)

### [전투 전] 약 550자
1. 문서고. 먼지, 철제 선반, 연도별 회의록 바인더. 개그 1발(하람이 라벨 상태에 감동한다 — 「이거 누가 정리했어? 천재인데」 → 리원 「나다.」).
2. **`F07` 결번 발견.** 3년 전 바인더를 꺼낸다. 9월 → **11월.** 10월이 없다.
   - 하람: 「10월 어디 갔어.」
   - 리원: 「결번이다.」 하람: 「그러니까 왜.」 리원: 「결번은 결번이야.」
   - 하람이 목록 대장을 확인한다. 결번 처리에는 **사유서와 서명**이 필요하다. 사유서는 없다. 그런데 **서명란에는 서명이 있다.** 「백리원」. 3년 전 필체 — **수첩 위쪽 종이의 그 어린 글씨와 같다.**
   - 하람: 「너 그때 몇 살이었어.」 리원: 「…열넷.」
3. **선택지 `RIW-02`** → 분기 대사 → 합류.
4. (분기 무관) 리원이 대화를 끝내려 하고, 하람이 화제를 돌린다 — 「그럼 이건.」 하람이 대장에서 찾아낸 **리원의 D열 등록 기록**을 내민다. 2년 전, 품명 「필기구 1점」, 서명 「백리원」.
   - 리원이 처음으로 대답을 못 한다. 하람: 「너도 잊고 싶은 게 있었네.」
   - 리원: 「…열지 마.」 하람: 「왜?」 리원: **「거긴 아무것도 없어. 진짜로.」**
5. 개봉. 안에는 **부러진 볼펜 한 자루.** 심이 종이를 뚫을 만큼 눌린 흔적.
6. **잔상 유입.** `fx: blurMemory`.
   - **`F19` 필수**: 「이번엔 냄새가 진했다. 소독약. 그리고 어디선가 물방울이 규칙적으로 떨어지는 소리.」 — 하람은 「문서고 곰팡이 냄샌가」로 닫는다.
   - 잔상 내용: 형광등 아래 긴 책상, 어른 여러 명의 목소리, 종이 넘기는 소리, 그리고 **아주 작은 손이 펜을 쥐고 있다.** 어른 하나가 「여기, 여기 서명.」 거기까지.
7. **검열자·리원형 출현.** 리원의 실루엣(단발 윤곽, 안경 형태)을 먹으로 칠한 형태. 목소리도 리원.
   - 검열자: 「그만 봐.」
   - 진짜 리원이 자기 목소리를 듣고 얼어붙는다. 리원: 「…뭐야, 저거.」
   - **`F20` 필수**: 하람 모놀로그 1~2줄 — 「검열자는 늘 내가 아는 말만 한다. 새로운 건 하나도 안 알려준다.」 → 그리고 **리원이 그것을 지적하려다 삼킨다:** 리원: 「저건 네가 —」 (말을 끊고) 「…아니야. 집중해.」
8. `battle` 커맨드.

### [B] `onWin` (약 200자)
- 검열자가 흩어지기 직전 ④「…미안해.」 리원 목소리로.
- 잔상이 계속되다 **마지막 1초에서 툭 끊긴다.**
- → `jump: { scene:'riw2s02', label:'win' }`

### [C] `onLose` (약 150자)
- 화면이 ■로 덮인다. 잔상이 70%에서 끊긴다. 하람이 무릎을 꿇고, 리원이 붙든다.
- → `jump: { scene:'riw2s02', label:'lose' }`

## 반드시 심을 복선 — **`F19`·`F20` 필수 (누락 = 재작업)**
| ID | 심는 방식 |
|---|---|
| `F19` **[환]** 소독약·링거 | 잔상 진입 지문 + 3턴째 SFX. 하람은 「문서고 곰팡이」로 닫는다 |
| `F20` **[환]** 검열자 정보 한계 | 하람 모놀로그 + **리원이 지적하려다 삼키는 것**(「저건 네가 —」) |

| 「내가 지운 거야」 | 검열자 입으로만. 진짜 리원은 부정한다 |

## 선택지·플래그 — `RIW-02`

프롬프트: **「결번. 사유서 없음. 서명 있음. 열네 살.」**

```
{ t:'choice', items: [
  { label:'"네가 뭘 지웠는지 말해."', goto:'riw02_a',
    set:[{key:'aff_riwon',op:'add',value:2},{key:'bond_riwon',op:'set',value:true}] },
  { label:'"…됐어. 안 물을게."',     goto:'riw02_b',
    set:[{key:'aff_riwon',op:'add',value:1}] }
]}
```
- **A**: 리원이 오래 침묵하고, 딱 한 문장만 준다. 「…언젠가는 말할게. 지금은 아니야.」 그리고 안경을 벗지 **않는다**(참는다). → `bond_riwon=true`. 분기 대사 약 70자.
- **B**: 리원이 「…고맙다」고 말한다. 그런데 그 말이 이 캐릭터 입에서 나온 게 이상하다. 하람이 「너 지금 고맙다고 했냐?」 → 리원 「기록하지 마.」 분기 대사 약 70자.
- 두 분기 → `label riw02_join`

## 톤 지시
**코미디 1 : 서정 4 : 불안 5.** 개그는 도입 1발까지.
리원의 방어는 **논리로** 이루어진다. 감정적으로 도망치지 않고, 정확한 문장으로 벽을 세운다. 「결번은 결번이야」 같은 동어반복이 그 벽의 재료.
잔상 묘사는 소리와 촉각 위주. 시각은 흐리게. **"작은 손이 펜을 쥐고 있다"가 이 씬의 이미지 한 방**이다.
검열자 대사는 지정된 6줄만.

## 금지 사항
- 폐기 대상이 **무엇인지** 절대 언급 금지. "10월 회의록"까지만.
- 잔상에서 어른들이 하는 말의 내용 금지. 「여기, 여기 서명.」이 최대치.
- 리원이 자백하지 말 것. 「언젠가는 말할게」가 최대치.
- 하람이 「네가 지웠어」의 목적어를 추측하지 말 것.
- 검열자를 객관 실재로 확정하는 지문 금지.
- 세아·윤슬 대사 금지.
- 하람의 이름 발화·표기 금지. 서명란에도 하람의 이름은 없다.
- 병원·병실이라는 단어 금지(냄새와 소리로만).
