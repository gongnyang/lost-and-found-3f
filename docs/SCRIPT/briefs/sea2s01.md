## 직전 상황 3줄 (스포일러 포함)
1. 하람은 세아의 3년 전 파일을 들었고, 세아는 그것이 "선배들 물려받은 파손 파일"이라고 둘러댔다. 둘 사이에 처음으로 벽이 생겼다.
2. 세아는 1년 전 D열에 SD카드 한 장을 맡겼다. 3년 전 그 파일의 원본이다. 맡기고도 잊지 못했다. — **개봉 전까지 정체 누설 금지.**
3. 검열자는 하람의 방어기제가 만든 환각이다. 이번엔 세아의 목소리와 실루엣을 하고 있다. 하람이 아는 목소리라서 그렇다. — **누설 금지. 단, `F20` 단서는 반드시 심는다.**

## 이 씬의 목표
- **플롯**: 세아가 D열에 맡긴 물건(SD카드) 개봉 → 전투2.
- **감정**: 두 사람이 처음으로 서로에게 정면으로 선다. 세아가 처음으로 하람을 말린다.
- **구조적 기능(최중요)**: **환각 단서 `F19`(소독약 냄새)와 `F20`(검열자가 아는 정보만 말함)을 심는다.** 1회차 반발 방지 장치. 누락 시 재작업.

## 비트 시퀀스 (권장)

### [전투 전] 약 550자
1. 보관소. 하람이 대장을 뒤져 **세아의 등록 기록**을 찾아낸다. 1년 전, 품명 「SD카드 1점」, 서명 「문세아」.
   - 하람: 「너 여기 뭐 맡겼더라.」 세아가 굳는다.
2. 세아의 저지. 평소 속사포가 사라지고 **말이 짧고 정확해진다** (이 캐릭터의 진심 모드).
   - 세아: 「열지 마세요.」 / 「그거 제 거예요.」 / 「제가 맡긴 건 제가 잊으려고 맡긴 거잖아요.」
   - 하람이 되묻는다: 「근데 너 안 잊었잖아.」 — **정곡.**
3. **선택지 `SEA-02`** → 분기 대사 → 합류.
4. 개봉. 상자 안에 SD카드 한 장. 라벨에 아무것도 안 써 있다.
5. **잔상 유입.** `fx: blurMemory`.
   - **`F19` 필수**: 「잔상이 들어오는데, 이번엔 냄새가 진했다. 소독약. 그리고 어디선가 물방울이 규칙적으로 떨어지는 소리.」 — 하람은 「방송실 습기인가」로 닫는다.
   - 잔상 내용: 사람 많은 야외, 스피커 하울링, 누군가의 손이 자기 등을 미는 감각. **거기까지.**
6. **검열자·세아형 출현.** 세아의 실루엣을 먹으로 칠한 형태. 목소리도 세아다.
   - 검열자: 「그만 봐.」
   - **옆에 진짜 세아가 서 있다.** 세아가 자기 목소리를 듣고 얼어붙는다. 세아: 「…뭐예요, 저거.」
   - **`F20` 필수**: 하람 모놀로그 1~2줄 — 「검열자는 늘 내가 아는 말만 한다. 새로운 건 하나도 안 알려준다. 방어기제라는 게 원래 그런 건가.」 → **합리화로 닫는다.**
7. `battle` 커맨드.

### 전투 파라미터 (연출 지시)
| 항목 | 지시 |
|---|---|
| 적 | `검열자·세아형` ×1. 세아의 실루엣, 트윈테일 윤곽, 목에 걸린 것의 형태까지 먹으로 |
| 목표 턴 | 5턴 생존. 3턴째에 검열 강도가 한 번 회복(초조함 연출) |
| 공통 대사 4종 | ①「그만 봐.」 ②「너 다쳐.」 ③「이건 네 거 아니야.」 ④「…미안해.」(마지막 턴 한정) |
| 세아형 개인 대사 2줄 | 「오빠, 듣지 마.」 / 「그 소리 나빠요.」 — **두 번째 줄에서 진짜 세아가 얼어붙는다.** 세아: 「나 저런 말 한 적 없는데.」 |
| 3턴째 연출 | 링거 낙하음 SFX 삽입 + 배경 격자에 커튼 무늬가 잠깐 겹침(1프레임) |
| 파티 | 세아 1인 + (플레이어 편의상) 시스템상 3인 파티 유지. **서사적으로는 세아만 말한다.** 리원·윤슬 대사 금지 |

### [B] `onWin` (약 200자)
- 검열자가 흩어지기 직전 ④「…미안해.」 세아 목소리로.
- 잔상이 계속 재생되는데 **마지막 1초에서 툭 끊긴다.**
- → `jump: { scene:'sea2s02', label:'win' }`

### [C] `onLose` (약 150자)
- 검열이 완전히 덮인다. 화면이 ■로 가득 찬다.
- 잔상이 70% 지점에서 끊긴다. 하람이 무릎을 꿇는다. 세아가 붙든다.
- → `jump: { scene:'sea2s02', label:'lose' }`

## 반드시 심을 복선 — **`F19`·`F20` 필수 (누락 = 재작업)**
| ID | 심는 방식 |
|---|---|
| `F19` **[환]** 소독약·링거 | 잔상 진입 지문 + 3턴째 SFX. 하람은 「방송실 습기」로 닫는다 |
| `F20` **[환]** 검열자의 정보 한계 | 하람 모놀로그 1~2줄로 명시. 그리고 세아의 「나 저런 말 한 적 없는데」로 보강 |
| `F09` | 세아가 맡긴 것이 SD카드라는 사실 |
| `F08` "오빠" | 검열자마저 「오빠」라고 부른다 — **이것이 세아가 얼어붙는 진짜 이유**(하람은 모른다) |

→ 전투 진입 직전 `set: [{key:'clue_censor_limit',op:'set',value:true}]`

## 선택지·플래그 — `SEA-02`

프롬프트: **「이거, 어떻게 열까.」**

```
{ t:'choice', items: [
  { label:'"네 앞에서 열게."',  goto:'sea02_a',
    set:[{key:'aff_sea',op:'add',value:2},{key:'bond_sea',op:'set',value:true}] },
  { label:'"혼자 볼게. 나가 있어."', goto:'sea02_b',
    set:[{key:'aff_sea',op:'add',value:1}] }
]}
```
- **A**: 세아가 「…네.」 하고 옆에 선다. 이후 전투 중 세아 대사 톤이 조금 더 단단해진다. 분기 대사 약 50자.
- **B**: 세아가 안 나간다. 「싫어요.」 결국 같이 본다. 분기 대사 약 50자. — **어느 쪽을 골라도 세아는 그 자리에 있다.** 선택은 세아의 태도만 바꾼다.
- 두 분기 → `label sea02_join`

## 톤 지시
**코미디 1 : 서정 4 : 불안 5.** 개그 금지에 가깝다(도입 1발까지 허용).
세아의 **진심 모드** 문법을 지킬 것: 말이 짧아지고, 존댓말이 완벽해지고, 감탄사가 사라진다. 이 낙차가 세아 연출의 전부다.
전투 파트는 대사 밀도를 낮추고 여백을 준다. 검열자 대사는 정확히 지정된 6줄(공통 4 + 개인 2)만.
하람은 끝까지 담담하다. 무서워하지 않는다.

## 금지 사항
- 3년 전 사고의 내용(무대 붕괴·부상·구조) **직접 서술 금지.** 잔상은 "사람 많은 야외 / 하울링 / 등을 미는 손"까지만.
- 세아가 자기 정체(그날의 후배)를 자백하지 말 것.
- 검열자를 객관 실재로 확정하는 지문 금지.
- 리원·윤슬 대사 금지(파티에 있어도 침묵).
- 잔상의 마지막 1초에 무엇이 있는지 암시 금지.
- 하람의 이름 발화·표기 금지. 검열자도 「오빠」만.
- 병원·병실이라는 단어 금지(냄새와 소리로만).
