## 직전 상황 3줄 (스포일러 포함)
1. 하람은 D열 최심부에서 라벨도 등록번호도 없는 상자를 발견했다(등록일 3년 전 10월 17일). 손을 뻗었는데 팔이 움직이지 않았다.
2. 세아는 3년 전 무대 붕괴에서 하람이 밀어내 살린 그 후배이며, 그날 이후 그를 "오빠" 외의 어떤 말로도 부르지 못한다. — **누설 절대 금지.**
3. 세아의 3년치 녹음은 취미가 아니라, 자기가 잊어버렸을 때를 대비한 증거 수집이다. — **누설 금지.**

## 이 씬의 목표
- **플롯**: 세아 루트 개시. 하람이 상자 얘기를 꺼내고, 세아가 "그럼 제가 도와드릴게요"로 동행 계약을 맺는다.
- **감정**: **이 루트에서 가장 즐거운 씬.** 세아의 코믹 스토킹이 폭주한다. 루트 전체 낙차의 원자재.
- **구조적 기능**: 세아의 녹음 강박을 캐릭터 개그로 완전히 소진시켜, `sea1s03`에서 그것이 뒤집힐 때의 충격을 확보한다.

## 비트 시퀀스 (권장)
1. 방송실 문을 여는데 이미 녹음 중. 세아가 「지금 문 여는 소리 3테이크째예요」라고 한다. **하람은 3번 여닫혀야 했다.**
2. **「오빠 목소리 데이터베이스」 프로젝트 발표.** 세아가 노트북을 열고 폴더 구조를 보여준다. 웃음/한숨/헛기침/「접수됐습니다」 같은 것들이 전부 분류돼 있다. 파일 수가 네 자리다.
   - 개그: 하람이 「이거 초상권 문제 있는 거 아니야?」 → 세아 「동의서 받았는데요?」 → 「언제?」 → 「작년 3월에 오빠가 사인한 방송부 협조 공문 뒷장에요.」 → 하람 「…나 사인 안 하는데.」 → 세아 「도장 찍으셨어요.」
   - ※ **하람이 서명 대신 도장을 쓴다는 사실**을 여기서 자연스럽게 흘린다(`F02` 보강).
3. 세아의 요구 폭주 3연타: ① 감정별 「접수됐습니다」 5종 녹음 ② 국어책 낭독 ③ 오빠라고 불렀을 때 대답하는 소리 30테이크. 하람이 다 해준다(귀찮아하면서).
4. **온도 전환 1** — 하람이 라벨 없는 상자 얘기를 꺼낸다. 세아의 반응이 0.5초 늦다. 그리고 **평소보다 크게** 「우와 미스터리다! 저 완전 좋아해요 그런 거!」 → 즉시 취재 모드. 하람은 눈치 못 챈다.
5. 세아가 동행을 자청한다. 명분: 「이거 방송부 특집으로 낼 거예요. 『3층 D열의 비밀』.」 하람이 「그거 학교에서 안 잘라줄걸」 → 세아 「잘리면 오빠랑 둘이서만 들어요.」 (러브코미디 비트)
6. **온도 전환 2 (짧게)** — 세아가 레코더를 만지작거리며 「오빠. 만약에요. 제가 오빠를 다 잊어버리면 어떡해요?」 → 하람 「그럼 이 파일 4천 개 틀어주면 되지.」 → 세아가 웃는다. `smile`이 아니라 `neutral`에 가까운 웃음. **지문 1줄:** 「세아는 웃었는데, 소리는 안 났다.」
7. 즉시 개그로 덮는다. 세아가 「지금 그거! 명대사! 다시 한 번!」 → 클로징.

## 톤 지시
**코미디 6 : 서정 3 : 불안 1.** **개그 비트 5개 이상.** 미연시 순도 최대치 구간.
세아 말투 준수: "-요"체 존댓말, 흥분하면 반말이 튀고 자동 수정("아 진짜 — …진짜요."), 속사포, 모든 것을 녹음 용어로 비유, 감탄사 "오옷/우와아/에엥?".
하람은 리액션 담당. 귀찮아하면서 다 해준다. 보호자 포지션.
온도 전환 2회는 각 2~3줄, **반드시 즉시 개그로 덮는다.** 여운 금지.

## 금지 사항
- 세아 `serious` 표정 **사용 금지**(루트 2장 전용). 비트 6의 웃음은 `neutral`.
- 3년 전 사고, 무대, 세아의 과거, 초등학교 시절 — 전부 금지.
- 레코더 안의 3년 전 파일 언급 금지(`sea1s03`이 최초).
- 하람이 세아의 이상함을 눈치채는 서술 금지.
- 하람의 이름 발화·표기 금지. 세아는 100% "오빠".
- 다른 히로인 등장 금지. 언급은 스치듯 1회까지 허용.
