## 직전 상황 3줄 (스포일러 포함)
1. 하람은 오늘 하루 CCTV·앨범·화단·기억 공백을 전부 마주치고 전부 합리화했다. 그러나 몸이 먼저 지쳐 있다.
2. 이 상자 안에 든 것은 코팅이 벗겨진 하람 자신의 명찰이다. 3년 전 윤슬의 유도로 하람이 직접 맡겼다. — **누설 절대 금지. 상자는 열리지 않는다.**
3. 대장의 등록일 3년 전 10월 17일은 무대 붕괴 다음 날이다. — **날짜만 보여주고 의미는 주지 않는다.**

## 이 씬의 목표
- **플롯**: `F03` 회수 개시 — 라벨 없는 상자 발견. 그리고 루트 분기 판정.
- **감정**: 공통 루트 전체에서 유일하게 하람이 **무서워하는** 씬. 단, 3줄 이내로만.
- **구조적 기능**: 플레이어에게 "이 게임의 목적지는 저 상자"라고 알린다. 미회수 조각 UI의 서사적 근거.

## 비트 시퀀스 (권장)
1. 밤의 보관소. 형광등 하나가 나갔다. 하람이 두고 온 라벨 프린터를 찾는다. 짧은 혼잣말 개그 1발(어둠 무서워하는 걸 인정 안 하는 톤).
2. D열 통로. 조명이 안 닿는 가장 안쪽. 프린터가 하필 거기 굴러가 있다.
3. **`cg_common_01` — 상자 발견.** 다른 물건들은 전부 라벨과 등록번호가 붙어 있는데, 맨 안쪽 하나만 **아무것도 없다.** 신발 상자 크기, 테이프로 두 번 감겨 있고, 먼지가 다른 것들보다 두껍다.
4. 하람이 대장을 확인한다. 그 자리에 해당하는 항목은 **등록번호도 품명도 없고, 등록일만 있다 — 「3년 전 10월 17일」.** 서명란은 비어 있다. 접수자란도 비어 있다.
   - 하람 모놀로그: 「내가 관리인이 된 게 작년 3월이니까, 이건 내가 접수한 게 아니다. 그럼 누가?」
5. **손을 뻗는다. 그리고 멈춘다.**
   - 이유를 하람 자신도 모른다. 손끝이 상자에 닿기 직전에 팔이 안 움직인다.
   - 모놀로그 2~3줄: 「손이 안 나갔다. 무서운 것도 아니고, 하기 싫은 것도 아니었다. 그냥 — 안 됐다.」
   - **여기서 처음으로 하람이 자기 상태를 이상하게 여긴다.** 공통 루트에서 허용되는 유일한 자각. 단 3줄.
6. 뒤로 물러나 문을 잠근다. 「내일. 내일 물어보자.」
7. **선택지 `CH-04`** → 루트 판정 → `jump`

## 선택지·플래그 — `CH-04` (결정타, `+4`)

프롬프트: **「이건 나 혼자 못 열겠다. 내일, 누구한테 먼저 말하지.」**

```
{ t:'choice', items: [
  { label:'문세아 — 어차피 다 녹음하고 다니니까', goto:'rt_pick',
    set:[{key:'aff_sea',op:'add',value:4},{key:'last_choice',op:'set',value:1}] },
  { label:'백리원 — 기록이라면 저 녀석이지',      goto:'rt_pick',
    set:[{key:'aff_riwon',op:'add',value:4},{key:'last_choice',op:'set',value:2}] },
  { label:'강윤슬 — 어른한테 물어보는 게 낫겠다',  goto:'rt_pick',
    set:[{key:'aff_yunseul',op:'add',value:4},{key:'last_choice',op:'set',value:3}] }
]}
```

### 루트 판정 (`label rt_pick` 이후)

```
{ t:'label', id:'rt_pick' }
// 하람 모놀로그 1~2줄 (공통, 선택 대상 언급 없이)

{ t:'if', cond:{all:[{key:'aff_sea',cmp:'gte',value:0}]}, then:'rt_eval' }
{ t:'label', id:'rt_eval' }
```

판정 순서(엔진 구현 지침 — 스크립트 워커는 아래 라벨만 준비하면 된다):
1. `aff_sea > aff_riwon && aff_sea > aff_yunseul` → `rt_sea`
2. `aff_riwon > aff_sea && aff_riwon > aff_yunseul` → `rt_riwon`
3. `aff_yunseul > aff_sea && aff_yunseul > aff_riwon` → `rt_yunseul`
4. 그 외(동점) → `rt_tiebreak` → `last_choice` 값으로 `rt_sea`(1) / `rt_riwon`(2) / `rt_yunseul`(3)

각 `rt_*` 라벨에서:
```
{ t:'set', ops:[{key:'route_id',op:'set',value:1}] }   // sea=1, riwon=2, yunseul=3
{ t:'jump', scene:'sea1s01' }                          // riw1s01 / yun1s01
```

**작성 지시**: `rt_sea`/`rt_riwon`/`rt_yunseul` 각각에 **전환 대사 1~2줄**을 붙인다(합계 60자 이내). 예: 「내일 아침, 방송실부터 가야겠다.」 — 히로인 이름을 직접 부르되 어느 루트로 가는지 명확히.

## 금지 사항
- **상자를 열지 말 것.** 만지지도 못한다.
- 상자 내용물에 대한 어떤 추측도 하람이 말하지 말 것. 「뭐가 들었을까」 정도까지만.
- 10월 17일이 무엇의 다음 날인지, 3년 전 사고와의 연결 — 전부 금지.
- 히로인 등장 금지. 전화·문자도 금지.
- 검열자 등장 금지. 잔상 금지.
- 하람의 이름 발화·표기 금지.
