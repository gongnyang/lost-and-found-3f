# c2s02 — 「점심의 삼국지」

| 항목 | 값 |
|---|---|
| 챕터 | 공통 2장 「이름 없는 관리인」 (2/5) |
| 장소 | 분기별: A `bg_broadcast`(방송실) / B `bg_cafeteria`(급식실 창가) / C `bg_counsel`(상담실) |
| 시간대 | 같은 날 점심시간 |
| 등장 | `haram`(시점) + **선택된 1인** |
| BGM | 분기별 `bgm_sea` / `bgm_riwon` / `bgm_yunseul` |
| 선행 | `c2s01` — 세 사람의 동시 습격, 전투 화제를 셋 다 돌림 |
| 후행 | `c2s03` |
| 예상 분량 | **600자** (도입 100 + 분기 3종 × 약 160자) |

---

## 직전 상황 3줄 (스포일러 포함)
1. 세 사람이 하람의 하루를 나눠 가진 상태다. 그중 점심 한 끼를 플레이어가 고른다.
2. 셋은 어제 하람이 굳어 있던 것을 목격했고, 오늘 그를 혼자 두지 않기로 각자 결심했다. — **누설 금지.**
3. 이 선택은 루트 분기의 두 번째 가중치다(`+3`).

## 이 씬의 목표
- **플롯**: 호감도 선택지 `CH-02` + 히로인별 2인 대화로 개별 매력 전시.
- **감정**: 순도 100% 러브코미디. 미스터리는 이 씬에 **없다.**
- **구조적 기능**: 각 히로인의 "혼자 있을 때의 온도"를 미리 보여줘 루트 선택에 정보를 준다.

## 비트 시퀀스

### [도입] (약 100자, 공통)
급식실로 향하는 계단에서 세 방향으로 문자/쪽지/부름이 동시에 온다. 하람 모놀로그 1~2줄로 상황 정리 후 즉시 선택지.

### 선택지 `CH-02`
프롬프트: **「점심. 한 군데밖에 못 간다.」**

```
{ t:'choice', items: [
  { label:'방송실 (문세아)',   goto:'lunch_sea',
    set:[{key:'aff_sea',op:'add',value:3},{key:'last_choice',op:'set',value:1}] },
  { label:'급식실 창가 (백리원)', goto:'lunch_riwon',
    set:[{key:'aff_riwon',op:'add',value:3},{key:'last_choice',op:'set',value:2}] },
  { label:'상담실 (강윤슬)',   goto:'lunch_yunseul',
    set:[{key:'aff_yunseul',op:'add',value:3},{key:'last_choice',op:'set',value:3}] }
]}
```

### [A] `lunch_sea` — 방송실 (약 160자)
- 세아가 점심 방송을 틀어 놓고 도시락을 먹고 있다. 밥 씹는 소리까지 녹음 중.
- 개그 2발: ① 하람의 젓가락질 소리를 "효과음 소스"로 채집 ② 하람이 한마디 할 때마다 볼륨 페이더를 올린다.
- 온도 전환 1줄: 세아가 갑자기 조용해지더니 「오빠 목소리는 안 잊어버릴 것 같아요.」 → 즉시 「아 지금 거 좋다 다시!」로 덮는다. **하람은 웃는다.**
- 마무리 → `label lunch_join`

### [B] `lunch_riwon` — 급식실 창가 (약 160자)
- 리원이 정확히 같은 자리, 같은 메뉴, 같은 순서로 먹고 있다. 반찬 배치가 규정처럼 정해져 있다.
- 개그 2발: ① 하람이 리원의 반찬 순서를 일부러 흐트러뜨림 ② 리원이 「급식 배식 순서 규정 제3조」를 인용하며 하람 식판을 재배열
- 온도 전환 1줄: 창밖 화단 쪽으로 시선이 갈 뻔한 리원이 고개를 반대로 돌린다. 하람은 눈치 못 챈다. **지문 1줄만.**
- 마무리 → `label lunch_join`

### [C] `lunch_yunseul` — 상담실 (약 160자)
- 윤슬이 편의점 삼각김밥 두 개와 종이컵을 내놓는다. 상담실에서 밥 먹으면 안 되는데 봐준다.
- 개그 2발: ① 윤슬이 어른답지 못하게 삼각김밥 비닐을 못 뜯음 ② 하람이 뜯어주자 「이런 건 진짜 못 하겠더라고요」하며 진지하게 부끄러워함
- 온도 전환 1줄: 윤슬이 「여기 오래 있진 마세요, 학생」이라 말하고 바로 「…아니다. 있어도 돼요.」로 번복. **하람은 농담으로 받는다.**
- 마무리 → `label lunch_join`

### [합류] `lunch_join` (약 40자)
점심 종. 하람 모놀로그 1~2줄. 오후 수업에 시청각실 자료 정리 심부름이 있다는 것만 언급 → `c2s03` 연결 고리.

## 선택지·플래그
- `CH-02` (위 참조). 3분기 전부 `lunch_join`으로 합류 후 `jump: c2s03`.
- 추가 플래그 없음.

## 톤 지시
**코미디 6 : 서정 2 : 불안 2.** 각 분기 개그 비트 2개 필수.
각 분기의 마지막 1줄만 온도가 떨어지고, **즉시 개그나 하람의 무심함으로 덮는다.** 여운을 주지 않는다 — 그게 이 씬의 규칙이다.
분기 길이는 반드시 균등하게(160자 ±20). 어느 히로인이 편애받는 인상을 주면 안 된다.

## 금지 사항
- 히로인 2인 이상 동시 등장 금지. 각 분기는 철저히 1:1.
- 미스터리 진전 **금지.** 이 씬은 정보를 주지 않는다. 온도 전환 1줄이 전부.
- 3년 전, 사고, 보관소의 기원, 검열자 — 전부 언급 금지.
- 히로인 `serious` 표정 금지.
- 하람의 이름 발화·표기 금지.
- 분기 대사에서 다른 히로인을 언급하지 말 것(격리 유지).

## 체크리스트
- [ ] 3분기 길이가 균등한가 (160자 ±20)
- [ ] 각 분기에 개그 2발 + 온도 전환 1줄이 있는가
- [ ] 온도 전환이 즉시 덮였는가 (여운 금지)
- [ ] `CH-02` 플래그 값이 정확한가 (`+3`, `last_choice`)
