## 직전 상황 3줄 (스포일러 포함)
1. 하람이 D열 최심부의 상자에 손을 댔고, 그 순간 발작했다. 세 사람이 그를 붙들고 있다(현실).
2. **이 씬에서 반전이 폭발한다**: 검열자는 실재하지 않는다. 하람의 해리성 방어기제가 만든 환각이며, 게임은 그것을 1인칭으로 성실히 렌더링해 왔다. 3년 전 무대 붕괴에서 하람은 후배를 밀어내다 중상을 입고 6개월 입원했다.
3. 최종 검열자는 하람 자신의 실루엣이고, 마지막 커맨드는 「내 이름을 말한다」 하나뿐이다.

## 이 씬의 목표
- **플롯**: UI 3단 박리를 통해 초자연 설정을 시스템 레벨에서 해체한다. `F16`~`F21` 일괄 회수.
- **감정**: 공포가 아니라 **깨달음.** 무섭게 쓰면 실패다 — 이 씬은 "아, 그랬구나"의 씬이다.
- **구조적 기능**: 이 게임의 최대 리스크(초자연 회수에 대한 "속았다" 반발)를 여기서 방어한다. **깔아둔 단서를 전부 명시적으로 호명하며 회수한다.**

### [A] 전투 전 (약 150자)
1. 익숙한 원고지 격자. 그런데 이번엔 **하람 혼자 서 있다가**, 히로인 3인이 옆에 나타난다. **나타나는 순서와 타이밍이 부자연스럽다** — 지문 1줄로 흘린다: 「셋이 언제 옆에 왔는지 나는 못 봤다.」
2. 적 등장. 검은 실루엣. 처음엔 형태를 알 수 없다.
   - 하람: 「…또 너냐.」
   - 검열자: 「보지 마.」 — 목소리가 **하람 자신의 것**이다. 하람이 그것을 알아채지 못한다(플레이어만 눈치챈다. 네임플레이트는 「검열자」).

### 전투 3단계 — UI 박리 (연출 지시)

| 단계 | 종료 트리거 | UI 변화 (`ui_strip_level`) | 배경 | 검열자 대사 | 삽입 대사 |
|---|---|---|---|---|---|
| **1단계** | 스크립트 이벤트(수치 무관) | 종료 시 **적 HP바 소실** (`=1`) | 원고지 격자에 **커튼 무늬**가 서서히 겹침 | 「보지 마.」 | 하람: 「HP바가 없어졌는데.」 → **아무도 대답하지 않는다** |
| **2단계** | 스크립트 이벤트 | 종료 시 **히로인 3인 스프라이트 소멸** (`=2`), 커맨드 4종 중 3종 회색 | 격자가 사라지고 흰 커튼과 링거대 | 「네가 부탁했잖아.」 | **지문: 「셋은 처음부터 여기에 없었다.」** ← 이 문장이 이 게임의 심장 |
| **3단계** | 마지막 커맨드 선택 | **전투 UI 전체 페이드아웃** (`=3`) | `bg_hospital` 완전 전환. BGM 정지, 심전도·링거 낙하음만 | 「…네가 맡겼잖아. 3년 전에.」 | 아래 §회수 시퀀스 |

### 단계 사이 회수 시퀀스 (약 500자) — **이 브리프의 핵심**

**2단계 종료 직후**, 하람이 자기 목록을 하나씩 호명하며 검열자에게 확인한다. 검열자는 부정하지 않는다.

- 하람: 「코피. 그거 네가 낸 게 아니지.」 → 검열자: 「…」 (`F16`)
- 하람: 「아무도 소리를 못 들었어. 여기서 나는 소리가 밖에 안 났으니까.」 (`F17`)
- 하람: 「CCTV에 나 혼자 서 있었어. 각도 문제가 아니었어.」 (`F18`)
- 하람: 「여기선 늘 소독약 냄새가 나. 이건 학교 냄새가 아니야.」 (`F19`)
- 하람: 「너는 내가 아는 말만 해. 새로운 건 한 번도 안 알려줬어. 왜냐면 —」 (`F20`)
  - **검열자가 처음으로 하람의 말을 이어받는다**: 「— 나는 너니까.」
- 하람: 「잔상은 항상 마지막 1초에서 끊겼어. 끊은 건 너지.」 → 검열자: **「끊은 건 너야.」** (`F21`)
- 그리고 하람이 마지막 단어를 찾는다. `true1s01`에서 못 찾았던 그 이름.
  - 「…너는 없구나.」
  - 검열자: 「응.」
- ※ **여기서 히로인 3인이 사라진다.** 지문: 「셋은 처음부터 여기에 없었다.」

**3단계 — 병실.**
- 배경 완전 전환. 하람은 서 있는데, 침대 위에도 **누군가 누워 있다.** 왼쪽 쇄골에 붕대(`F23` 회수).
- 검열자가 처음으로 형태를 드러낸다. **하람 자신의 실루엣.** 네임플레이트가 「검열자」에서 「???」로 바뀐다 — **하람의 네임플레이트와 같아진다.**
- 검열자: 「네가 맡겼잖아. 3년 전에. 이름을 부르면 네가 부서지니까, 부르지 말자고. 다 같이.」
- 하람: 「…내가?」
- 검열자: 「네가 제일 먼저.」
- ※ **이 두 줄이 반전의 마지막 조각이다.** 세 사람의 연극에 하람 본인도 처음엔 동의했다는 것. 이것이 이 이야기를 "가해"만이 아니라 "합의된 비극"으로 만든다.
- 하람 모놀로그 2~3줄: 「기억이 안 났다. 당연하지. 그걸 안 나게 하려고 한 거니까.」
- **마지막 커맨드 제시.**

### 마지막 커맨드 (연출 지시)
- 커맨드 창이 다시 뜨는데, 항목이 4개인데 3개가 회색이다.
- 회색 항목의 라벨은 전부 「—」. 툴팁도 「—」.
- 활성 항목 1개: **「내 이름을 말한다」**
- 선택 시 화면 암전 + `fx: whiteFlash`.

### [B] `onWin` = 커맨드 선택 성공 (약 150자)
- 하람이 입을 연다. **소리가 안 나온다.** 세 번 시도한다.
- 네 번째에 **아주 작게** 소리가 나온다. 그런데 **그 소리가 자막에 표시되지 않는다** — 자막은 「" ————— "」로 처리.
- 검열자가 흩어진다. 흩어지면서 마지막 한 마디: 「…이제 네 차례야.」
- `set: [{key:'battle03_done',op:'set',value:true},{key:'ui_strip_level',op:'set',value:3}]`
- → `jump: { scene:'true1s05', label:'after_win' }`

### [C] `onLose` = 커맨드 선택 실패/타임아웃 (약 100자)
- 하람이 끝내 아무 말도 못 한다. 화면이 서서히 어두워진다.
- 검열자: 「괜찮아. 아직 아니어도 돼.」 ← **자기 자신에게 하는 말이라 다정하다.**
- 병실 소리가 멀어지고, 하람이 보관소 바닥에서 눈을 뜬다.
- `set: [{key:'battle03_done',op:'set',value:true},{key:'ui_strip_level',op:'set',value:3}]`
- → `jump: { scene:'true1s05', label:'after_lose' }`

## 톤 지시
**코미디 0 : 서정 4 : 불안 6.** 개그 완전 금지.
**무섭게 쓰지 말 것.** 이 씬의 정서는 공포가 아니라 **납득**이다. 검열자는 위협적이지 않다 — 오히려 지쳐 있고, 조금 다정하다. 자기 자신이니까.
하람이 목록을 호명하는 시퀀스는 **한 줄씩 짧게, 리듬감 있게.** 설명하지 말고 열거한다.
병실 묘사는 **소리와 냄새로만.** 부상 묘사 금지(전연령) — 커튼, 링거, 심전도, 붕대 위치까지.
「셋은 처음부터 여기에 없었다.」는 **한 줄로 독립시킨다.** 앞뒤 여백.

## 금지 사항
- **3년 전 사고의 전모를 여기서 말하지 말 것.** 검열자는 "이름을 부르면 부서진다 / 네가 먼저 맡겼다"까지만. **무대 붕괴·세아를 밀어냈다는 사실은 `true1s05`의 자산.**
- 하람의 이름을 **화면에 글자로 표시하지 말 것.** onWin에서도 자막은 「————」.
- 히로인 3인의 대사 금지(1~2단계에서도 침묵 — 이것이 나중에 "없었다"의 복선).
- 부상·피·수술 묘사 금지.
- 검열자를 악역으로 그리지 말 것.
- 하람의 분노·오열 금지.
- 「환각」·「해리」 같은 의학 용어 금지. 하람은 그 단어를 모른다.
