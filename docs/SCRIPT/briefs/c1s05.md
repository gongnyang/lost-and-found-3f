## 직전 상황 3줄 (스포일러 포함)
1. 3학년 의뢰인이 반년 전 맡긴 손목시계를 개봉했고, 하람에게 잔상이 흘러들었다.
2. 검열자는 실재하지 않는다. 하람의 해리성 방어기제가 만든 환각이며, 실제로는 하람이 선반 앞에서 굳어 있고 세 사람이 그를 붙들고 있다. — **누설 절대 금지.**
3. 세 사람은 이 상황을 3년째 겪어 왔다. 그래서 조금도 당황하지 않는다. — **누설 금지. 반응 속도로만 표현.**

## 이 씬의 목표
- **플롯**: 전투 시스템 규칙 학습(튜토리얼). 승리 조건 = 3턴 버티기.
- **감정**: **코믹하게.** 이 전투는 무섭지 않다. 셋이 신나서 떠드는 학원물 이벤트로 소비되어야 한다.
- **구조적 기능**: 초자연 낚시. 플레이어가 "아 이 게임 능력물이구나"라고 완전히 믿게 만든다.

## 씬 구성 (전투 래퍼)

```
[A] 전투 전 대사 (약 200자)
{ t:'battle', id:'btl_common01', onWin:'win', onLose:'lose' }
{ t:'label', id:'win' }   → 승리 대사 (약 120자) → jump c1s06 (label win)
{ t:'label', id:'lose' }  → 패배 대사 (약 80자)  → jump c1s06 (label lose)
```

### [A] 전투 전 (약 200자)
1. 하람 모놀로그 1~2줄 — 원고지 격자 같은 공간, 먹 번짐. 잔상이 재생되는 동안 이 공간이 유지된다.
2. 히로인 3인 각 1줄씩 반응 (성격 순도 100%):
   - 세아: 신나서 마이크를 들이댄다. 「우와아 이거 소리 진짜 특이해요! 오빠 이거 저작권 누구예요?」
   - 리원: 이미 앞에 서 있다. 「셋. 좌·중·우. 우측이 가장 빨라. 기록해 두겠다.」
   - 윤슬: 종이컵을 내려놓는 소리. 「…괜찮아요. 오래 안 걸려요.」 ← **이 대사가 나중에 다르게 읽힌다. 그냥 다정하게 쓸 것.**
3. 검열자 대사 — 단어만. 「■■■.」 「지워.」 「보지 마.」
4. 하람이 규칙을 한 번 더 못 박는다. 「3턴만 버티면 돼요. 재생 끝날 때까지.」

### 전투 파라미터 (연출 지시 — 수치 밸런스는 범위 밖)
| 항목 | 지시 |
|---|---|
| 적 | `검열자·낙서` ×3. SD 2.5등신, 먹으로 칠한 동그라미에 팔다리. **귀엽다** |
| 승리 조건 | 3턴 생존 = 잔상 완주. '검열 강도' 게이지 0 도달로 표시 |
| 특수 연출 | 적이 행동할 때마다 **화면 하단 대사창의 텍스트 일부가 ■로 칠해진다**(1턴 1회). 3턴째엔 화자 네임플레이트까지 잠깐 ■가 된다 — **트루 전투3의 UI 박리 예고** |
| SFX | 붓으로 종이 긁는 소리, 지우개 문지르는 소리 |
| 히로인 스킬 플레이버 | 세아=「샤우팅」(음압으로 밀어냄) / 리원=「규정 제12조」(방어 버프) / 윤슬=「따뜻한 거」(회복) — **필살기 이름은 전부 캐릭터 결함 개그** |

### [B] onWin (약 120자)
- 검열자가 먹물처럼 흩어지고 잔상이 끝까지 재생된다. 아버지가 시계를 채워 주던 손, 정도의 짧은 이미지 1컷.
- 세아: 「기록 완료! 오빠 이거 편집해서 드릴게요.」 리원: 「…3턴. 예측대로다.」 윤슬: 「수고했어요.」
- `set: [{key:'battle01_won', op:'set', value:true}]`
- `jump: { scene:'c1s06', label:'win' }`

### [C] onLose (약 80자)
- 잔상이 90% 지점에서 끊긴다. 화면이 하얗게 튄다.
- 하람: 「…아, 놓쳤다.」 리원: 「기록. 실패 1건.」 세아: 「다음엔 제가 더 크게 소리 지를게요!」
- 게임오버 없음. 스토리 그대로 진행.
- `jump: { scene:'c1s06', label:'lose' }`

## 톤 지시
**코미디 6 : 서정 1 : 불안 3.** 학원 능력물 튜토리얼의 즐거움. 무섭게 쓰면 실패다.

전투 중 히로인 대사는 짧고 리드미컬하게. 각 1~2줄.

## 금지 사항
- 하람이 전투에 참전하지 않는다. **하람은 재생 대상이자 관측자다.** 이 배치를 설명하지 말 것 — "나는 움직일 수 없었다" 정도의 1인칭 서술로만.
- 검열자를 객관 실재로 확정하는 지문 금지.
- 검열자가 **새로운 정보를 말하는 것 금지**(`F20`의 일관성). 하람이 이미 아는 단어만.
- 코피·무음 등 환각 단서는 여기서 안 나온다(`c1s06` 담당).
- 3년 전 사고, 병실, 히로인의 비밀 — 전부 금지.
- 하람의 이름 발화·표기 금지.
- 히로인 `serious` 표정 금지.
