# seaGE — [굿엔딩] 「오빠의 목소리」

| 항목 | 값 |
|---|---|
| 챕터 | 문세아 루트 굿엔딩 |
| 장소 | `bg_broadcast_sunset`(석양의 방송실) |
| 시간대 | 그로부터 몇 주 뒤, 방과후 |
| 등장 | `haram`(시점) / `sea` |
| BGM | `bgm_sea`(편곡·느리게) |

| 엔딩 ID | `ge_sea` |

## 직전 상황 3줄 (스포일러 포함)
1. 하람은 세아가 3년 전 축제 날 이 학교에 있었다는 것, 그리고 그를 "오빠"라고밖에 부를 수 없다는 것까지만 알고 멈췄다.
2. 그는 더 캐묻지 않기로 했다. 세아도 더 말하지 않기로 했다. 두 사람은 그 합의 위에 일상을 다시 쌓았다.
3. 진실은 그대로 남아 있다. 하람은 여전히 자기 이름을 모르고, 세아는 여전히 그를 부르지 못하며, 잡음은 벗겨지지 않았다. — **이 엔딩은 그 사실을 알면서 행복한 척하는 엔딩이 아니라, 정말로 행복한 엔딩이다.** 그래서 다시 읽으면 무섭다.

## 이 씬의 목표
- **플롯**: 진실을 모르는 채 맞는 다정한 결말. 미회수 조각 2/3이 남았다는 여운.
- **감정**: **따뜻하게.** 슬프게 쓰면 실패다. 플레이어가 "좋은 엔딩이었다"고 느껴야 트루에서 뒤집힌다.
- **구조적 기능**: 재독 장치. 모든 문장이 **중의적**이어야 한다 — 1회차엔 로맨스로, 2회차엔 비극으로.

## 비트 시퀀스 (권장)
1. 몇 주 뒤. 폐쇄 안건이 부결되어 보관소는 살아남았다(1줄로 처리). 일상이 돌아왔다. — **어휘 고정**: riwGE와 동일하게 「폐쇄 안건, 부결」로만 서술한다. "심의 통과" 표현 금지(가결로 오독됨).
2. 방송실. 세아의 특집 「3층 D열의 비밀」은 결국 방송되지 못했다(교내 심의 반려). 대신 세아가 **매일 방송 말미에 정체불명의 한 마디**를 넣기 시작했다.
   - 개그 1발: 다른 학생들이 「그 마지막에 오빠라는 거 뭐임?」 하고 수군댄다. 학교 괴담이 하나 늘었다.
3. **중의적 문장 구역 (이 씬의 핵심).** 아래 종류의 대사·지문을 3~4개 배치한다. 1회차엔 애정 표현, 2회차엔 죄책감으로 읽히는 것들.
   - 세아: 「저는 오빠를 하루도 안 빼먹고 녹음할 거예요. 앞으로도요.」
   - 세아: 「오빠가 오빠인 걸 제가 계속 기억할게요.」
   - 하람 모놀로그: 「세아는 나를 부를 때 한 번도 헷갈린 적이 없다. 그게 좀 신기했다.」
   - 세아: 「오빠가 뭘 잊어도 괜찮아요. 제가 다 갖고 있으니까.」
4. 하람의 일상 정리 모놀로그 3~4줄. **행복하다.** 그는 자기 이름을 여전히 모르지만, 그걸 결핍으로 느끼지 않는다.
   - 「나는 여전히 존재감이 없고, 아무도 내 이름을 안 부른다. 근데 한 명은 매일 나를 부른다. 그거면 됐다.」
5. **`bond_sea` 분기** (마지막 3~4줄만).
6. 마지막 컷: 세아가 오늘 파일을 저장한다. 폴더 스크롤바가 오늘도 조금 더 작아졌다. `{ t:'ending', id:'ge_sea' }`

## `bond_sea` 분기 (마지막 3~4줄)

```
{ t:'if', cond:{key:'bond_sea', cmp:'eq', value:true}, then:'ge_warm', else:'ge_plain' }
```

- **`ge_warm`** (약 90자): 세아가 이어폰 한 짝을 건네며 「오늘 거, 같이 들으실래요?」 둘이 나란히 앉아 오늘 하루치 소리를 듣는다. 마지막 트랙은 하람이 「접수됐습니다」라고 말하는 소리. 세아가 그걸 세 번 반복 재생한다.
- **`ge_plain`** (약 90자): 세아가 혼자 이어폰을 끼고 오늘 파일을 검수한다. 하람은 옆에서 라벨을 붙인다. 아무 말 없이 편안한 시간. 세아가 문득 「오빠」하고 부르고, 하람이 「응」 하고 대답하는 것으로 끝.

두 분기 모두 마지막 줄은 동일하게 둔다:
> 「내일도 여기 있을 거예요.」 / 「알았어.」

## 반드시 회수/유지할 복선
| ID | 처리 |
|---|---|
| `F08` "오빠" | **회수하지 않는다.** 애정 표현으로만 소비시킨다 — 이것이 재독 장치의 핵심 |
| `F09` 3년치 녹음 | 「앞으로도 계속」으로 미래형 전환. 스크롤바 마지막 컷 |
| `F01` 이름 은폐 | 하람이 그것을 **행복하게 수용**한다. 「그거면 됐다.」 |
| 조각 2/3 미회수 | 엔딩 롤 직후 UI에 「미회수 조각 1/3」 표시 (엔진 처리) |

## 선택지·플래그
- 선택지 없음.
- 진입 시 이미 `frag_sea=true`.
- 엔딩 커맨드 `{ t:'ending', id:'ge_sea' }` 실행 시 엔진이 글로벌에 `g_clear_sea=true`, `g_frag_sea=true` 기록.

## 톤 지시
**코미디 3 : 서정 6 : 불안 1.** 개그 비트 2개(방송 괴담 소문, 세아의 과잉 녹음 루틴).
**불안 1은 화자가 아니라 문장 구조에서만 나온다.** 하람은 완전히 행복하다.
문장을 길게 쓰지 말 것. 짧고 담백한 행복. 미사여구 금지.
"영원히"·"평생" 같은 단어를 쓰지 말고, 「내일」·「앞으로도」 같은 **가까운 미래**만 말하게 한다. 이 게임의 세 사람은 먼 미래를 약속할 자격이 없다는 것을 알고 있다.

## 금지 사항
- **진실을 암시하는 직접 서술 절대 금지.** 중의적 문장으로만.
- 세아가 미안해하거나 죄책감을 드러내는 대사 금지. 밝아야 한다.
- 3년 전, 사고, 잡음, 검열자, 상자 — **전부 언급 금지.** 이 엔딩은 그것들을 잊은 척이 아니라 정말로 접어둔 시간이다.
- 리원·윤슬 등장·언급 금지.
- 하람의 이름 발화·표기 금지.
- 세아 `serious` 금지. `smile`/`laugh`/`neutral`만.
- 슬픈 BGM·비 오는 날씨 등 비극 신호 금지. 날씨는 맑다.

## 체크리스트
- [ ] 중의적 문장이 3개 이상 배치됐는가 (1회차 로맨스 / 2회차 비극)
- [ ] 하람이 **진심으로 행복한가** (동정 유발 금지)
- [ ] "영원히"류의 먼 미래 약속이 없는가
- [ ] `bond_sea` 두 분기가 작성되고 마지막 줄이 통일됐는가
- [ ] 진실 관련 소재(사고·상자·검열자)가 하나도 안 나왔는가
