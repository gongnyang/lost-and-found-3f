## 직전 상황 3줄 (스포일러 포함)
1. 하람은 방금 CCTV에서 자기 혼자 서 있는 영상을 봤고, "각도 문제"로 닫았다. 그는 지금 조금 지쳐 있다.
2. 세 사람은 교문 앞에서 각자 다른 이유로 하람을 기다리고 있다. 실제로는 그를 혼자 보내지 않으려는 것이다. — **누설 금지.**
3. 이 선택은 루트 분기의 세 번째 가중치다(`+3`).

## 이 씬의 목표
- **플롯**: 호감도 선택지 `CH-03`. 그리고 **셋의 연기 균열 2회차**(마지막 노출).
- **감정**: 노을. 하루의 끝. 러브코미디가 조금 부드러워진다.
- **구조적 기능**: `c2s05`의 고독한 밤 씬으로 넘어가기 전 마지막 온기.

## 비트 시퀀스

### [도입] (약 130자)
1. 교문 앞. 셋이 **각자 다른 위치에서, 각자 다른 척하며 서 있다.** 세아는 벤치에서 녹음 중, 리원은 게시판을 보는 척, 윤슬은 정문 화단 옆.
2. 하람이 나오자 셋이 **거의 동시에** 고개를 돌린다.
   → **[균열 2회차]** 하람: 「…너네 진짜 짜고 다니는 거 아니지?」
   → 세아 「아닌데요?」 / 리원 「근거는?」 / 윤슬 「그건 그렇고요.」 — **세 개의 부정이 순서대로 튀어나온다.**
   → 하람 모놀로그 1줄: 「대답이 세 개나 왔다. 하나면 될 걸.」 그리고 넘긴다.
3. 즉시 선택지.

### 선택지 `CH-03`
프롬프트: **「집 방향이 다 다르다. 한 명하고만 갈 수 있다.」**

```
{ t:'choice', items: [
  { label:'문세아와',   goto:'home_sea',
    set:[{key:'aff_sea',op:'add',value:3},{key:'last_choice',op:'set',value:1}] },
  { label:'백리원과',   goto:'home_riwon',
    set:[{key:'aff_riwon',op:'add',value:3},{key:'last_choice',op:'set',value:2}] },
  { label:'강윤슬과',   goto:'home_yunseul',
    set:[{key:'aff_yunseul',op:'add',value:3},{key:'last_choice',op:'set',value:3}] }
]}
```

### [A] `home_sea` (약 130자) — 하천 산책로
- 세아가 걸으면서 발소리를 녹음한다. 하람 발소리와 자기 발소리 박자를 맞추려는 개그.
- 개그 1발 + 온기 1줄: 세아가 「오빠는 왜 남의 물건만 맡아줘요? 오빠 건 안 맡겨요?」 → 하람 「난 잊고 싶은 게 없는데.」 → 세아가 **한 박자 멈췄다가** 「…그러네요.」 즉시 웃음으로 덮음.
- → `label home_join`

### [B] `home_riwon` (약 130자) — 상가 골목
- 리원이 보폭까지 규칙적이다. 하람이 일부러 박자를 어긋나게 걷는 개그.
- 개그 1발 + 온기 1줄: 리원이 「너, 오늘 자료실에서 뭐 봤어?」라고 **너무 정확한 질문**을 던진다. 하람이 「그냥 먼지」라고 답하자 리원은 「…그래.」로 끝낸다. 안도한 것처럼 들리지만 하람은 모른다.
- → `label home_join`

### [C] `home_yunseul` (약 130자) — 버스 정류장
- 윤슬이 버스를 두 대 보낸다. 하람이 「누나 버스 놓쳤어요」 → 「알아요.」
- 개그 1발 + 온기 1줄: 윤슬이 「학생은, 집에 가면 누가 이름 불러줘요?」라고 묻는다. 하람 「어… 그러고 보니 없네요. 혼자 살아서.」 → 윤슬이 **종이컵을 세게 쥔다.** 그리고 「그건 그렇고요. 저 버스 타야겠다.」
- → `label home_join`

### [합류] `home_join` (약 30자)
하람 모놀로그 1~2줄. 「오늘은 좀 길었다. 근데 보관소에 두고 온 게 있다.」 → `c2s05`로.

## 톤 지시
**코미디 5 : 서정 4 : 불안 1.** 노을 씬이므로 앞 씬들보다 부드럽다. 개그는 각 분기 1발이면 충분.
각 분기의 온기 1줄은 **반드시 히로인 쪽에서 나온 질문**이고, **하람의 무심한 대답이 히로인을 아프게 한다.** 하람은 그걸 전혀 모른다. 이 구조를 세 분기 모두 지킨다.
분기 길이 균등(130자 ±15).

## 금지 사항
- 히로인 2인 이상 동시 대화 금지(도입부 3연속 부정 제외).
- 하람이 히로인의 반응 변화를 **눈치채는 서술 금지.** 지문에서도 "표정이 굳었다" 수준까지만, 해석 금지.
- 3년 전, 사고, 검열자, 보관소 기원 — 언급 금지.
- 히로인 `serious` 표정 금지. 세아·윤슬의 흔들림은 `worry`로.
- 하람의 이름 발화·표기 금지.
- 분기 대사에서 다른 히로인 언급 금지.
