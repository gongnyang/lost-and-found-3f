## 직전 상황 3줄 (스포일러 포함)
1. 하람은 대장 최초 등록 서명 「YS」를 봤고, 윤슬이 무너지는 것을 봤고, 그럼에도 "이 학교 사람도 아니고"로 스스로 부정했다.
2. 윤슬이 D열에 맡긴 물건은 **자기 고등학교 학생증**이다. 3년 전 축제 운영위원 신분증이 붙어 있다. — **개봉 시 학생증까지만 보이고, 소속 학교명은 화면에 안 나온다.**
3. 검열자는 하람의 방어기제가 만든 환각이다. 이번엔 윤슬의 목소리와 실루엣을 하고 있다. — **누설 금지. 단, `F20` 단서는 반드시 심는다.**

## 이 씬의 목표
- **플롯**: 윤슬이 맡긴 학생증 개봉 → 전투2.
- **감정**: 윤슬이 처음으로 **먼저** 열자고 한다. 도망치던 사람이 멈춰 선 순간.
- **구조적 기능(최중요)**: **환각 단서 `F19`(소독약·링거)와 `F20`(검열자가 아는 정보만 말함)을 심는다.** 1회차 반발 방지 장치. 누락 시 재작업.

## 비트 시퀀스 (권장)

### [전투 전] 약 550자
1. 상담실. 윤슬이 어제 일을 사과한다. 「어제는 제가 실례했어요.」 하람이 「누나 실례한 적 없는데요」라고 받는다. 조용한 개그 1발.
2. 하람이 대장 기록을 내민다. 「누나. 여기 학생증 맡기셨더라고요.」
   - 윤슬이 놀라지 않는다. **이미 알고 있었다는 표정.** 그리고 처음으로 자기가 먼저 말한다.
   - 윤슬: 「…네. 제가 맡겼어요.」
   - 하람: 「왜요?」
   - 윤슬: 「잊고 싶어서요. 여기 규칙이 그렇잖아요.」
   - 하람: 「누나 그거 진짜라고 믿어요? 도시전설이잖아요.」
   - 윤슬: **「…네. 믿어요.」** ← 이 대답이 이상하다. 하람도 잠깐 멈춘다.
   - ※ **`F14` 배치.** 만든 사람만이 할 수 있는 대답이다. 설명 금지.
3. **선택지 `YUN-02`** → 분기 대사 → 합류.
4. 개봉. 안에는 **코팅이 살짝 들뜬 학생증 한 장.** 사진 속 얼굴은 지금보다 어리다. 교복이다.
   - 하람: 「…누나 고등학교 때 사진이네요.」
   - **소속 학교명은 화면에 나오지 않는다.** 하람이 그 부분을 확인하려는 순간 잔상이 시작된다. (연출로 차단)
5. **잔상 유입.** `fx: blurMemory`.
   - **`F19` 필수**: 「이번엔 냄새가 진했다. 소독약. 그리고 어디선가 물방울이 규칙적으로 떨어지는 소리.」 — 하람은 「상담실 방향제인가」로 닫는다.
   - 잔상 내용: **점검표를 든 손.** 볼펜으로 체크 표시를 하는 소리. 여러 사람의 웃음소리. 스피커 테스트. 그리고 누군가 「이 정도면 됐죠?」 거기까지.
6. **검열자·윤슬형 출현.** 윤슬의 실루엣(롱헤어 윤곽, 긴 가디건 자락)을 먹으로 칠한 형태. 목소리도 윤슬.
   - 검열자: 「그만 봐.」
   - 진짜 윤슬이 얼어붙는다. 윤슬: 「…제 목소리네요.」 — **놀라지 않고 확인하듯 말한다.** 이 반응이 다른 두 히로인과 다르다.
   - **`F20` 필수**: 하람 모놀로그 1~2줄 — 「검열자는 늘 내가 아는 말만 한다. 새로운 건 하나도 안 알려준다. 방어기제라는 게 원래 그런 건가.」
   - 보강: 윤슬이 조용히 덧붙인다. 「…그건 학생 안에서 나오는 거예요.」 하람: 「네?」 윤슬: 「…아니에요. 조심하세요.」 ← **정답을 말했는데 하람이 못 알아듣는다.**
7. `battle` 커맨드.

### 전투 파라미터 (연출 지시)
| 항목 | 지시 |
|---|---|
| 적 | `검열자·윤슬형` ×1. 롱헤어 윤곽, 발목까지 오는 가디건 자락, 두 손으로 감싼 종이컵 형태까지 먹으로 |
| 목표 턴 | 5턴 생존. 3턴째에 검열 강도 1회 회복 |
| 공통 대사 4종 | ①「그만 봐.」 ②「너 다쳐.」 ③「이건 네 거 아니야.」 ④「…미안해.」(마지막 턴 한정) |
| 윤슬형 개인 대사 2줄 | 「여기까지만 해요.」 / **「제가 만든 거예요.」** — 두 번째 줄에서 진짜 윤슬이 종이컵을 놓칠 뻔한다. 윤슬: 「…」 (부정하지 않는다) |
| ※ 차별점 | 세아·리원은 「나 저런 말 한 적 없다」고 부정한다. **윤슬만 부정하지 않는다.** 이것이 윤슬 루트의 시그니처 |
| 3턴째 연출 | 링거 낙하음 SFX + 배경 격자에 커튼 무늬 1프레임 |
| 파티 | 윤슬 1인만 발화. 세아·리원 대사 금지 |

### [B] `onWin` (약 200자)
- 검열자가 흩어지기 직전 ④「…미안해.」 윤슬 목소리로. **그리고 진짜 윤슬도 동시에 같은 말을 한다.** 두 목소리가 겹친다.
- 잔상이 계속되다 **마지막 1초에서 툭 끊긴다.**
- → `jump: { scene:'yun2s02', label:'win' }`

### [C] `onLose` (약 150자)
- 화면이 ■로 덮인다. 잔상이 70%에서 끊긴다. 하람이 주저앉고, 윤슬이 붙든다. 손이 익숙하다.
- → `jump: { scene:'yun2s02', label:'lose' }`

## 반드시 심을 복선 — **`F19`·`F20` 필수 (누락 = 재작업)**
| ID | 심는 방식 |
|---|---|
| `F19` **[환]** 소독약·링거 | 잔상 진입 지문 + 3턴째 SFX. 하람은 「상담실 방향제」로 닫는다 |
| `F20` **[환]** 검열자 정보 한계 | 하람 모놀로그 + **윤슬의 「그건 학생 안에서 나오는 거예요」** — 정답을 주는데 못 알아듣는 구조 |
| `F14` 도시전설의 저자 | 「…네. 믿어요.」 + 검열자의 「제가 만든 거예요.」 + **윤슬이 부정하지 않음** |
| 학생증 | 코팅 들뜬 학생증. **소속 학교명 비노출** |

→ 전투 진입 직전 `set: [{key:'clue_censor_limit',op:'set',value:true}]`

## 선택지·플래그 — `YUN-02`

프롬프트: **「누나 거예요. 제 마음대로 열면 안 되죠.」**

```
{ t:'choice', items: [
  { label:'"누나 앞에서 열게요."', goto:'yun02_a',
    set:[{key:'aff_yunseul',op:'add',value:2},{key:'bond_yunseul',op:'set',value:true}] },
  { label:'"…안 열래요."',        goto:'yun02_b',
    set:[{key:'aff_yunseul',op:'add',value:1}] }
]}
```
- **A**: 윤슬이 「…네. 그래 주세요.」 그리고 옆에 앉는다. → `bond_yunseul=true`. 분기 대사 약 70자.
- **B**: 하람이 상자를 도로 놓는다. 그런데 **윤슬이 직접 연다.** 「제가 열게요. …이건 제 몫이에요.」 → 전개 동일. 분기 대사 약 70자.
- 두 분기 → `label yun02_join`

## 톤 지시
**코미디 1 : 서정 4 : 불안 5.** 개그는 도입 1발까지.
윤슬 루트 전투의 차별점은 **윤슬이 도망치지 않는다는 것**이다. 세아는 얼어붙고 리원은 부정하는데, 윤슬은 조용히 인정에 가까운 침묵을 한다. 그 담담함이 무섭게 쓰여야 한다.
잔상 묘사는 **소리와 손**으로만. 「점검표를 든 손」이 이 씬의 이미지 한 방.
검열자 대사는 지정된 6줄만.

## 금지 사항
- 학생증의 **소속 학교명 노출 절대 금지.**
- 3년 전 사고 내용 금지. 잔상은 "점검표 / 체크 소리 / 웃음 / 이 정도면 됐죠?"까지만.
- 윤슬이 자백하지 말 것. 「…네. 믿어요.」와 침묵이 최대치.
- 「그건 학생 안에서 나오는 거예요」에 하람이 반응하지 말 것. 「네?」 한 마디로 넘긴다.
- 검열자를 객관 실재로 확정하는 지문 금지.
- 세아·리원 대사 금지.
- 하람의 이름 발화·표기 금지.
- 병원·병실이라는 단어 금지(냄새와 소리로만).
