## 0. 호칭 매트릭스 (전 캐릭터 교차표) — **최우선 규칙**

### 0.1 하람을 부르는 법 (이름 은폐 정합)

이 게임의 물리 법칙이다. `true1s05`의 지정 지점 전까지 **어떤 캐릭터도, 어떤 상황에서도 「하람」이라는 음절을 발화하지 않는다.** 지문에서도 쓰지 않는다(1인칭 "나").

| 화자 | 하람 호칭 | 발화 특징 |
|---|---|---|
| `sea` 문세아 | **"오빠"** (100%) | 예외 없음. 놀릴 때도 "오빠아", 화날 때도 "오빠." 이유를 물으면 "그냥 그렇게 부르고 싶어서" |
| `riwon` 백리원 | **"…너"** / "관리인" / "거기" | 부르기 직전 **반드시 0.5초 멈춘다**. 지문으로 매번 명시: 「리원은 한 박자 쉬고 말했다.」 공식 석상에선 "분실물 보관소 관리 담당 학생" |
| `yunseul` 강윤슬 | **"학생"** / "관리인 학생" / "저기요" | 존댓말. **매 상담을 "오늘은 이름, 알려주실래요?"로 연다** — 이 질문 자체가 호칭 회피의 알리바이 |
| `mob` 교사 | 출석번호 **"14번"** | 명부에 이름 표기가 없다. 교사는 이상하다고 생각하지 않는다 |
| `mob` 학생 | "관리인" / "야" / "저기" | |
| `censor` 검열자 | 부르지 않는다 | 2인칭 "너"만 사용 |

**예외 해제 지점**: `true1s05`의 이름 입력 확정 직후 단 한 번, 세아 → 리원 → 윤슬 순서로 각 1회. 그리고 `trueEnd`에서 자유롭게 사용 가능. 그 전엔 금지.

**자연스러움 장치**: 하람 본인이 이 상황을 전혀 이상하게 여기지 않는다. "제가 원래 존재감이 없어서" 로 전부 설명한다. 오히려 새 사람을 만날 때마다 자기소개를 먼저 하는 습관이 있어서 대화가 성립한다.

## 1. 정하람 `haram` — 「???」

### 프로필
| 항목 | 값 |
|---|---|
| 나이·학년 | 17세, 한서고 2학년 5반 (출석번호 14번) |
| 역할 | 분실물 보관소 관리인 (봉사시간 대체 아르바이트) |
| 시점 | 플레이어 시점. 전 지문이 하람의 1인칭 |
| 네임플레이트 | `name_revealed=false` → 「**???**」 / true → 「정하람」 |
| 좋아하는 것 | 정리, 라벨 붙이기, 남의 이야기 들어주기 |
| 특기 | 초면인 사람에게 3초 안에 자기소개 시작하기 |

### 말투 시그니처
- **어미**: 존대는 "-요"체(과한 "-습니다" 금지). 또래에겐 "-지", "-잖아", "-거든".
- **입버릇**: **"괜찮아요, 저 원래 존재감 없어서."** — 게임 내 총 4~5회 배치(공통 2회, 루트 1회, 트루 1회로 의미가 뒤집힌다).
- 자주 쓰는 말: "일단 라벨부터 붙이자", "접수됐습니다", "…어라?", "그럴 수도 있지 뭐."
- **자학을 농담으로 처리한다.** 절대 진지하게 서러워하지 않는다. 이게 이 캐릭터의 잔인함이자 매력.
- 모놀로그는 담백한 단문. 화려한 비유 금지. 관찰 → 대수롭지 않게 넘김의 리듬.
- 남의 말을 잘 받아친다. 리액션 담당이지 개그 발신자가 아니다.

### 외형
검은 머리, 앞머리가 눈썹을 살짝 덮는 정도. 눈매가 순하고 처져 있다. 교복은 항상 단정하지만 넥타이만 늘 조금 헐겁다. 왼쪽 손목에 얇은 검은 밴드(습관적으로 만진다). **왼쪽 쇄골에 5cm 정도의 옅은 흉터** — 본인은 언제 생겼는지 모른다(`F23`). 가방에 라벨 프린터와 마스킹테이프가 상시 들어 있다. 노트 앞장 이름 칸은 늘 찢겨 있다(`F02`).

### 표정 8종
`neutral`(순한 무표정) / `smile`(작은 미소, 기본값에 가까움) / `laugh`(눈 감고 웃음) / `blush`(귀만 빨개짐, 표정은 그대로) / `sad`(웃는 채로 눈만 안 웃음 — **이 캐릭터의 핵심 표정**) / `worry`(눈썹 안쪽 올라감) / `surprise`(눈 크게, 입 살짝) / `serious`(밴드 만지던 손을 멈춘 얼굴)
※ 하람은 시점 캐릭터라 스프라이트 등장이 드물다. **CG와 전투3에서만 사용**. 우선순위 낮음.

### 비밀과 죄책감
본인이 자각한 비밀: **자기 필체를 모른다.** 서명할 일이 생기면 늘 도장이나 체크로 대체한다. 그리고 3년 전 봄부터 가을까지 기억이 없다 — "원래 기억력이 나빠서"로 처리한다(`F15`).
자각 못 한 것: 그가 무대 붕괴에서 후배를 밀어내고 중상을 입은 당사자이며, 6개월 입원했고, 세 사람이 그의 이름을 지웠다는 것.
**죄책감이 없다는 것이 그의 비극**이다. 그는 자기가 가해당했다는 사실조차 모르므로 화낼 수 없다. 트루엔딩에서 그가 요구하는 것이 사과가 아니라 "그럼 지금 불러줘"인 이유.

### 루트별 태도
- 세아 루트: 귀찮아하면서 다 들어준다. 보호자 포지션.
- 리원 루트: 능글맞게 규정을 비튼다. 이 루트에서 가장 말이 많다.
- 윤슬 루트: 유일하게 조금 어리광이 나온다. 어른 앞에서 아이가 되는 톤.
- 트루: 담담하다. 끝까지 목소리를 높이지 않는다.

## 2. 문세아 `sea` — 방송부 1학년

### 프로필
| 항목 | 값 |
|---|---|
| 나이·학년 | 16세, 한서고 1학년 2반 |
| 소속 | 방송부 (아나운서 겸 음향) |
| 하람과의 관계 | 비혈연 후배. 그런데 "오빠" |
| 3년 전 | 초등학교 5학년. **무대 붕괴 때 하람이 밀어내 살린 그 후배**(당시 축제 초청 초등 합창단으로 무대 뒤에 있었다) |
| 소지품 | 목에 건 구형 IC 레코더(3년째 같은 기종), 여분 배터리, SD카드 케이스 |

### 말투 시그니처
- **어미**: "-요"체 존댓말 기본인데 흥분하면 반말이 튀어나온다("아 진짜 — …진짜요."). 이 자동 수정이 개그 포인트.
- **속사포**. 한 호흡에 두세 문장을 몰아친다. 쉼표 많은 긴 문장 → 갑자기 짧은 문장 한 방.
- 자주 쓰는 말: "녹음 갑니다", "지금 거 다시 한 번만요", "레벨 좋아요", "오빠 지금 그거 명대사인데?"
- 감탄사: "오옷", "우와아", "에엥?"
- **모든 대화를 녹음 용어로 비유한다** — "그 말 좀 노이즈 낀 것 같은데요", "지금 그거 편집 못 해요."
- 진지해질 때는 **말이 갑자기 짧아지고 존댓말이 완벽해진다.** ("…네. 알겠습니다.") 이 낙차가 세아 연출의 전부다.

### 외형
삐뚤게 묶은 낮은 트윈테일(항상 한쪽이 조금 낮다). 목에 건 구형 IC 레코더 — 은색, 모서리가 닳았다. 교복 위 방송부 완장(왼팔). 키가 작고 몸짓이 크다. 손톱은 짧게 깎여 있다(장비 다룰 때 방해돼서). 귀에 항상 이어폰 한 짝이 걸려 있다.

### 표정 8종
`neutral`(입 살짝 벌린 채) / `smile`(활짝, 눈 반달) / `laugh`(몸 젖히며) / `blush`(양볼 전체, 손으로 가림) / `sad`(입꼬리 내리고 레코더 만지작) / `worry`(눈썹 팔자, 이어폰 빼는 동작) / `surprise`(눈 크게, 레코더 들어올림) / `serious`(**웃음기 완전히 사라진 무표정 — 세아 최강 카드. 루트 후반과 트루에서만**)

### 비밀과 죄책감
3년간 매일 녹음해 왔다. **잊지 않으려고가 아니라, 자기가 잊었을 때를 위한 증거로.** 그날 그 애가 자기를 밀어냈고, 자기는 무사했고, 그 애는 6개월 뒤에 이름 없는 사람으로 돌아왔다. 열세 살의 세아가 할 수 있었던 유일한 저항이 녹음이었다.
"오빠"는 애교가 아니다. 이름을 부르면 안 된다는 규칙 안에서 그를 부를 수 있는 **유일한 단어**였다(`F08`).
레코더 안에 3년 전 그날의 파일이 있다. 세아는 그걸 3년간 한 번도 끝까지 듣지 못했다.

### 루트 요약
`sea1s01` 코믹 스토킹 → `sea1s02` 청취자 0명 라디오, 처음으로 서로의 목소리를 듣는다 → `sea1s03` 3년 전 파일 발견, 이름 부분만 잡음 → `sea2s01` 세아가 D열에 맡긴 물건(SD카드) 개봉, 검열자·세아형 → `sea2s02` 잔상이 마지막 1초에서 끊김. **조각①: "세아는 3년 전 이 학교에 있었다. 그리고 누군가 이름을 불렀다."**
굿엔딩 `seaGE`: 진실을 모른 채, 세아가 매일 방송 말미에 "오빠"를 한 번씩 넣는 일상. — 재독 시 전부 다르게 읽힌다.

## 3. 백리원 `riwon` — 학생회 서기

### 프로필
| 항목 | 값 |
|---|---|
| 나이·학년 | 17세, 한서고 2학년 5반 (하람과 같은 반) |
| 소속 | 학생회 서기 (2년 연임). 문서·회의록 총괄 |
| 하람과의 관계 | 동급생. 3년째 같은 학교, 2년째 같은 반 |
| 3년 전 | 중학교 3학년 겸 학생회 연계 서기(중고통합 학생회). **폐기 결의안에 서기로 서명한 것이 열네 살의 리원** |
| 소지품 | 겨드랑이에 낀 바인더, 검은 펜 3자루(색 통일 강박), **개인 수첩**(절대 남에게 안 보여줌) |

### 말투 시그니처
- **어미**: 반말인데 문어체. "-야", "-지", "-잖아"보다 **"-다", "-군", "-인가"** 계열이 섞인다. "그건 규정 위반이야." "…그런 건가."
- **조항 인용 개그**: 뭐든 "학생회 규정 제○조 ○항에 따르면"으로 시작한다. 조항 번호는 매번 다르고, 하람이 "그거 진짜 있는 조항이야?"라고 물으면 대답을 안 한다.
- 자주 쓰는 말: "기록해 두겠다", "근거는?", "…비효율적이야", "그건 내 소관이 아니야."
- **말끝을 흐리지 않는다.** 대신 **말 앞에 멈춘다** — 하람을 부를 때의 0.5초(`F10`). 지문 필수.
- 당황하면 문장이 짧아지고 존댓말이 튀어나온다. ("…아, 아닙니다.")
- 감정 표현을 사실 진술로 대체한다. "기쁘다" 대신 "이 결과는 만족스럽다."
- **울지 않는다.** 트루에서도 "…규정 위반이야, 이거 보는 거"라고만 말한다.

### 외형
턱선에 딱 떨어지는 단발 + 오른쪽에 검은 헤어핀 2개(늘 평행하게). 은테 안경(생각할 때 검지로 브릿지를 민다). 교복 리본이 자로 잰 듯 수평. 항상 겨드랑이에 A4 바인더. 손끝에 늘 펜 자국. 자세가 지나치게 곧다. 명찰은 학생회 규격대로 왼쪽 가슴 정확한 위치에.

### 표정 8종
`neutral`(무표정, 안경 반사) / `smile`(입꼬리 3mm — 아는 사람만 안다) / `laugh`(**희소. 입 가리고 어깨만 흔들림**) / `blush`(귀와 목만 붉어지고 표정은 무표정 유지) / `sad`(시선을 바인더로 내림) / `worry`(안경 브릿지 미는 손) / `surprise`(눈 크게, 펜 떨어뜨림) / `serious`(안경 벗은 얼굴 — **리원의 최종 카드**)

### 비밀과 죄책감
리원은 잊지 않는 사람이 아니다. **잊지 않으려고 매일 아침 자기에게 다시 알려주는 사람**이다.
3년 전, 학생회 권한으로 명부·회의록·앨범·출석부에서 그의 이름 표기를 지웠다. 어른들이 시켜서가 아니라 **자기 판단으로**, "이 애 앞에서 이름을 부르지 말자"는 결론에 도달해서. 그것이 옳다고 믿었고, 지금도 완전히 틀렸다고는 생각하지 못한다. 그게 더 괴롭다.
수첩 맨 앞장에 매일 아침 같은 문장을 다시 쓴다: **「오늘도 잊지 마. 저 애 이름은 정하람이야. 네가 지웠어.」** 3년치, 1,000장이 넘는다. 열네 살의 삐뚤빼뚤한 글씨부터 지금의 반듯한 글씨까지(`F11`).
회의록 3년 전 10월분 결번은 분실이 아니라 **폐기 결의**였고, 그 결의안 서기 서명이 자기 것이다(`F07`).

### 루트 요약
`riw1s01` 폐쇄 심의 감사관 파견, 원칙 대 즉흥 → `riw1s02` 규정을 같이 어기는 하루, 비 오는 복도의 우산 하나 → `riw1s03` 수첩 앞장을 힐끗 본다(이름 부분은 손에 가려 안 보임) → `riw2s01` 결번 추궁, 리원이 맡긴 물건(부러진 펜) 개봉, 검열자·리원형 → `riw2s02` 3년치 수첩. **조각②: "3년 전 10월, 학생회는 무언가를 폐기하기로 결의했다. 서명은 백리원."**
굿엔딩 `riwGE`: 리원이 처음으로 규정에 없는 문장을 회의록에 남긴다 — 「관리인 학생, 오늘도 출근함.」

## 4. 강윤슬 `yunseul` — 상담실 인턴

### 프로필
| 항목 | 값 |
|---|---|
| 나이 | 20세, 지역 사립대 사회복지학과 3학년 |
| 소속 | 한서고 Wee클래스 실습생(주 3일). 정식 상담교사 아님 |
| 하람과의 관계 | 비혈연, 3살 위. 학교에서 유일하게 하람에게 존댓말을 쓰는 어른 쪽 사람 |
| 3년 전 | 한서고 3학년, 축제 운영위원. **무대 붕괴의 유일한 성년(만 18세) 목격자** |
| 소지품 | 늘 두 손으로 감싸 쥔 종이컵, 낡은 상담 파일 바인더, 진주 헤어핀 |

### 말투 시그니처
- **어미**: 전면 존댓말 "-요"체. 상대가 고등학생이어도 무너뜨리지 않는다. 다만 **매우 부드러운 존대** — "-실래요?", "-일까요?", "-네요."
- 자주 쓰는 말: "**오늘은 이름, 알려주실래요?**"(상담 오프닝 고정 문구, `F12`), "천천히 해도 돼요", "그건 그렇고요", "따뜻한 거 드실래요?"
- **화제 전환 버릇**: 대화가 3년 전, 이름, 보관소의 기원에 닿으면 **반드시 "그건 그렇고요" 또는 종이컵/날씨/간식 화제로 튼다.** 예외 없음. 이 버릇 자체가 캐릭터의 정체다.
- 질문으로 되받는다. 자기 이야기를 거의 하지 않는다.
- 침묵을 두려워하지 않는다. 지문에 「…」를 오래 둘 수 있는 유일한 캐릭터.
- 당황하면 **말이 빨라지고 존댓말이 더 정중해진다.** ("아, 그건, 그러니까 — 죄송해요, 제가 잠깐.")

### 외형
흑발 롱, 살짝 웨이브. 왼쪽에 작은 진주 헤어핀. 발목까지 오는 아이보리 니트 가디건(사계절 내내). 안에는 늘 무채색 셔츠. 늘 두 손으로 감싸 쥔 종이컵(내용물은 대개 코코아 — 본인은 커피를 못 마신다). 목소리가 낮고 느리다. 눈 밑에 옅은 그늘. 손목 안쪽에 볼펜으로 쓴 메모 흔적이 자주 있다.

### 표정 8종
`neutral`(부드러운 미소가 기본값) / `smile`(고개 살짝 기울임) / `laugh`(**희소. 입 가리고 소리 없이**) / `blush`(종이컵으로 입가 가림) / `sad`(미소를 유지한 채 시선만 내려감 — **하람의 `sad`와 같은 구조. 의도적 페어링**) / `worry`(눈썹 안쪽, 종이컵 쥔 손에 힘) / `surprise`(종이컵 흔들림, 눈 크게) / `serious`(종이컵을 내려놓는 얼굴 — 윤슬이 도망치지 않기로 한 순간)

### 비밀과 죄책감
윤슬은 이 학교 졸업생이고, 3년 전 사고를 처음부터 끝까지 본 사람이다. 무대 하중 점검표에 "이상 없음"이라고 체크한 축제 운영위원 중 하나였다.
어설픈 심리학 지식으로 **'기억을 물건에 맡기면 잊는다'는 도시전설을 지어냈고, 분실물 보관소를 만들었다.** D열 규칙을 정한 것도, 하람이 스스로 이름표를 D열에 맡기도록 유도한 것도 그녀다. 대장 최초 등록자 서명란의 `YS`가 그 증거(`F04`).
상담 기록지의 이름 칸을 3년째 비워 두고 있다(`F13`). 매번 "오늘은 이름 알려주실래요?"라고 묻는 것은 — 언젠가 그가 스스로 말해 주기를 기다리는 것이자, 자기가 저지른 일을 매주 확인하는 자해다.
속죄를 위해 이 학교에 돌아왔다. 그리고 아직 아무에게도 그 말을 하지 못했다.

### 루트 요약
`yun1s01` 정기면담, 어른의 다정함과 화제 전환 → `yun1s02` 옥상 코코아 두 잔, 이 게임에서 가장 숨 쉬기 편한 씬 → `yun1s03` 대장 최초 등록 페이지의 `YS`, 처음으로 화제 전환에 실패한다 → `yun2s01` 윤슬이 맡긴 물건(오래된 학생증) 개봉, 검열자·윤슬형 → `yun2s02` 종이컵을 내려놓지만 고백 직전에서 끊긴다. **조각③: "이 보관소를 만든 사람은 강윤슬이고, 그녀는 3년 전 이 학교에 있었다."**
굿엔딩 `yunGE`: 상담 기록지 이름 칸이 오늘도 비어 있고, 윤슬은 내일도 같은 질문을 할 것이다. 따뜻하고, 다시 읽으면 무섭다.

## 6. 표정 사용 규칙 (에셋 발주 연계)

- 캐릭터당 8종 고정: `neutral / smile / laugh / blush / sad / worry / surprise / serious`
- 우선순위: 히로인 3인 8종 전량 필수(24장). `haram`은 `neutral/smile/sad/serious` 4종만 우선 발주(CG·전투3용).
- **`laugh`는 리원·윤슬에게 희소 자원이다.** 각 캐릭터당 전 게임에서 3회 이내로 쓴다. 남발 금지.
- **`serious`는 각 히로인 루트 2장과 트루에서만 사용.** 공통 1·2장에서 히로인 `serious` 사용 금지 — 반전 낙차를 깎는다.
- 하람의 `sad`(웃는 채로 눈만 안 웃음)와 윤슬의 `sad`(미소 유지, 시선만 내려감)는 **의도적으로 같은 구조**로 그린다. `true1s05`에서 둘이 같은 표정을 하는 컷이 있다.
